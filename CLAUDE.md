# ai-playbooks: notes for Claude

This is Sean Frazer's **public** portfolio of AI-assisted work: case studies, post-mortems, protocols, prompts and Claude Code skills. Employers and other builders read it.

## Rules
- **Privacy first.** Never include his kids' names, photos or progress, app database contents, tokens, keys, account or site IDs, private repo URLs, or local file paths. Screenshots of Course Quest come only from demo mode (`?preview=1`). Run a privacy grep before every commit.
- **Honest and measured.** Every case study has the problem, the setup, a timeline, results with numbers, what broke, and what changed. Failures stay in.
- **Plain writing.** Short sections, no hype, no AI clichés.
- **Adding a project:** add `case-studies/<date-or-name>.md` with images in `case-studies/assets/` (web-sized JPGs, no EXIF), link it from README "Highlights" if it's strong, and pull any reusable process into `protocols/`, `prompts/` or `skills/`.
- **Publishing:** this repo is public on GitHub. Never push without Sean's go-ahead in that session.
